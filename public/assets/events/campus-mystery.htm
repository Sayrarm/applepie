Event Description

✎ edit in archive

Complete all surveys to claim the Main Story Branch 5-Star Memory Xavier: Outcast's Voyage x1 for free.

Gameplay

Investigation Progress

Players can choose to visit one location each day to complete a survey at the selected location. If a daily survey was missed, additional attempts can be purchased to make up for the missed day(s).

Survey Reward

Complete all 6 surveys to claim the 5-Star Memory Xavier: Outcast's Voyage for free. Once the event has concluded, this Memory will become available in the Wishing Well exchange shop after a game update.
